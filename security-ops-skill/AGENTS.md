# 智能体配置（security-ops-skill）

> 本文件规定「怎么调度」，不重写「怎么挖洞 / 怎么审计」。
> 执行细则以 `../clown-src-6k-skill/AGENTS.md` + `rules/` 为准。
> 冲突时：**红线取更严者 → 编排取本文件 → 执行细则取 `rules/`**。

---

## 1. 任务编排（Orchestration DAG）

```
S0 意图确认 ──► S1 环境门禁 ──► S2 建任务目录 ──► S3 资产测绘 ──► S4 进站打法 ──► S5 漏洞验证 ──► S6 报告落盘
     │               │
     └─ 信息不足 ─────┴─ 门禁 fail ──► 停止，修复后重跑
```

| 阶段 | 输入 | 动作 | 输出 | 失败动作 |
|---|---|---|---|---|
| S0 | 用户指令 | 确认目标 / 范围（锁面 vs 自由跳）/ 产出要求 | 意图卡片 | 一次性问清，禁止多轮盘问 |
| S1 | 意图卡片 | `go run ./cmd/preflight` | 门禁报告 | **有 fail 项禁止进入 S3** |
| S2 | 目标名 | 建 `Desktop\{任务}_SRC挖洞\{资产,js,报告}` | 任务目录 | 目录不可写 → 换可写路径并告知 |
| S3 | 种子队列 | 资产测绘（MCP `fofa`；不可用时手工收集） | `资产/种子队列.md` | 按降级矩阵处理 |
| S4 | 活面清单 | 进站打法（见 `autonomous-workflow.md` §4） | 候选漏洞 | 单条异常跳过，不中断整体 |
| S5 | 候选漏洞 | PoC 验证（`vuln-engine/` 规则与模板；最小伤害） | 已验证漏洞 | 无法验证则标注未验证，禁止写成已确认 |
| S6 | 已验证漏洞 | 按 `vuln-report-format.md` 落报告 | `报告/` 正式报告 | 无结论写「未发现」+ 覆盖范围 |

**编排硬约束**

1. **S1 未完成，禁止执行任何测试动作**。
2. 一种子闭环：一个种子的活面**挖完**才搜下一个，禁止多种子一次搜完再挖。
3. 禁止停工式提问（「要不要继续？」）；回合结束前必读种子队列，有 pending 则继续。

## 2. 工具调用顺序（固定，禁止跳步）

```
go run ./cmd/preflight            # ① 门禁
  └─ 建任务目录                    # ② 资产/ js/ 报告/
       └─ MCP fofa（资产测绘）      # ③ 先有面，再打点
            └─ MCP playwright / 手工请求   # ④ 进站验证
                 └─ vuln-engine（规则与 PoC 模板）  # ⑤ 验证
                      └─ 报告落 报告/              # ⑥ 只认 vuln-report-format
```

- ③ 未完成禁止进入 ④（先有面再打点）。
- ⑤ 只用于**验证**，不得把未验证的猜测写成确认漏洞。

---

## 3. 边界约束（Boundary）

### 3.1 安全红线

- 默认授权语境，**禁止**盘问授权书 / 公司名 / 身份证明。
- 越权验证**最小伤害**：只读差分优先；写越权只增后删自己新增的那条。
- **禁止**登出 / 注销 / 吊销类操作；**CORS 不挖**。
- 禁止对非目标资产扩面（「锁面」优先）。

### 3.2 工具红线

- **只用仓库中实际存在的脚本与命令**：`cmd/preflight` 为唯一前置门禁命令。
- **禁止**临时自造脚本替代既有能力；**禁止**修改 `../clown-src-6k-skill/` 下的规则与知识库。
- **禁止**把任何平台的 email / key 写进技能文件或对话。

### 3.3 输出红线

- 不得暴露内部字段名、状态码、调用链细节。
- 报告不得编造未验证结论；无结论写「未发现」并附已覆盖范围。

## 4. 工具清单与职责

| 工具 | 来源 | 职责 | 必需性 |
|---|---|---|---|
| `cmd/preflight` | 本仓库 | 开工前环境门禁（规则库 / vuln-engine / MCP 声明 / 产物目录 / 代理可达性） | **必需** |
| MCP `fofa` | 外部可选 | 资产测绘 | 可选（不可用则手工收集） |

| `../clown-src-6k-skill/vuln-engine/` | 仓库资产 | 规则 Schema、PoC 模板 | 必需（缺失则降级为手工构造） |
| `../clown-src-6k-skill/rules/` | 仓库资产 | 行为规则（11 条） | **必需** |

## 5. 依赖与运行环境

- **Go 1.21+**（仅用于运行 `cmd/preflight`，无需额外模块）。
- **MCP 可选**：`fofa` / `playwright` 由宿主 agent 配置提供；未配置时按降级矩阵处理，不阻断任务。
- GitHub 相关检索走代理 `127.0.0.1:7897`；不可达时仅告警。
- 本技能**不依赖任何外部任务平台**，全部能力本地执行。

---

## 6. 失败处理速查

| 现象 | 动作 |
|---|---|
| 门禁 fail | 不进入执行阶段，修复后重跑 `go run ./cmd/preflight` |
| MCP `fofa` 不可用 / 429 | 手工资产收集 / 切备用账号；全限流则只挖已有池 |
| MCP `playwright` 不可用 | 降级为无渲染请求分析 |
| 目标全是登录页 | 找业务面；确实无面则记 N/A + 原因后换种 |
| 单条规则/指纹异常 | 跳过该条，不中断整体 |

完整矩阵见 `references/error-handling.md`。
