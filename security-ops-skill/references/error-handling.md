# 错误处理与降级

> 主文件：../SKILL.md §4。本文件为完整降级矩阵与排障要点。
> 本技能**不依赖任何外部任务平台**，所有错误均在本地链路内处理。

## 1. 通用原则

1. **严禁输出闲话**——错误即按话术表给一句话，然后停下等用户。
2. **禁止静默无限重试**——同一动作重试不超过 3 次，仍失败则转人工说明。
3. **错误分级处理**：单条规则/目标异常 → 跳过继续；环境与工具缺失 → 降级；红线触碰 → 立即停止。
4. **经验记录**：满足「任务执行中 + 2 次以上尝试才解决 + 已解决」三条件时，
   在 `references/` 下追加记录（**只追加，禁止修改/删除已有条目**）。

## 2. 降级矩阵

| 场景 | 降级动作 | 用户话术 |
|---|---|---|
| MCP `fofa` 不可用 | 改用手工资产收集，标注结果可能不完整 | 资产搜索工具暂不可用，已改用手工收集，结果可能不完整 |
| FOFA 429 限流 | 切备用账号；全限流则只挖已有池 | 资产搜索遇到限流，正在切换账号 |
| MCP `playwright` 不可用 | 降级为无渲染请求分析 | 浏览器工具暂不可用，已降级为静态分析 |
| `vuln-engine/` 规则缺失 | 手工构造 PoC，标注为手工验证 | 规则库不完整，已改用手工构造验证 |
| GitHub 代理 `127.0.0.1:7897` 不可达 | 跳过依赖 GitHub 的检索 | （无需告知，仅影响检索广度） |
| 单条指纹/规则异常 | 跳过该条，不中断整体 | （无需告知） |
| 目标打不开 / 全是登录页 | 找业务面；确实无面则记 N/A + 原因后换种 | 该目标无明显业务面，已记录并切换 |

## 3. 硬阻塞（禁止继续，必须先解决）

| 阻塞项 | 处理 |
|---|---|
| 门禁存在 `fail` 项 | **禁止开工**，修复后重跑 `go run ./cmd/preflight` |
| 规则库 `rules/` 缺失必需条目 | **禁止开工**，先恢复规则文件 |
| 产物目录不可写 | **禁止开工**，先换可写目录 |
| 目标不在授权范围且无法澄清 | **禁止开工**，向用户确认范围 |

## 4. 禁止事项（会破坏现有功能）

- ❌ 禁止自行编写/发明新脚本（只能用仓库中实际存在的命令，当前门禁命令为 `cmd/preflight`）
- ❌ 禁止凭空调用不存在的命令或脚本
- ❌ 禁止把内部字段（状态码、内部字段名、工具错误细节）直接抛给用户
- ❌ 禁止在未验证的情况下把猜测写成已确认漏洞
- ❌ 禁止触碰安全红线（登出/注销、CORS、超范围扩面、批量真资损）
