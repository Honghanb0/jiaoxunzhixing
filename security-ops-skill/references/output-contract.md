# 输出契约

> 主文件：../SKILL.md §3。本文件定义产出约定。

## 1. 语言与暴露面

- 发给用户的消息**必须中文**；CVE 编号、工具名、协议名等专有英文术语可保留。
- **禁止**暴露内部字段名、状态码、工具错误细节、下游调用链。
- 错误场景统一使用 [error-handling.md](error-handling.md) 的话术。

## 2. 目录约定

```
Desktop\{任务}_SRC挖洞\
├── 资产\       # 公网 URL + 种子队列.md
├── js\         # 提取的 JS
└── 报告\       # 正式报告
```

产物目录不可写时，换用可写路径并在回复中说明。

## 3. 报告规范

- 正式报告**只认** `../../clown-src-6k-skill/rules/vuln-report-format.md`（两张表）。
- 挖什么认 `src-value-hunting.md`；与知识库冲突**以 rules 为准**。
- 每条结论必须可复现：目标 URL / 请求要点 / 判定依据；**未验证的猜测禁止写成已确认漏洞**。
- 未发现问题时写「未发现」并附**已覆盖范围**，禁止空白收尾。
