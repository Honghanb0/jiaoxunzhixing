# 万平灵探

> 企业资产收集 · 攻击面测绘 · 人工审计 · 安全扫描 一体化桌面工具（Electron）

**万平灵探** 是一款面向已授权资产的安全评估与暴露面管理（EASM）本地化桌面工具。
它在完成多维资产采集后，提供**人工审计**（研判真实资产 / 误报）、对确认资产进行
**安全扫描**（连通性测试、高危指纹 / 未授权访问 / 明文传输识别），并输出**格式化的 EASM 报告**。

所有探测均为被动 / 只读式，不含任何破坏性操作；数据不出本机。

---

## 一、功能概览

| 阶段 | 能力 | 说明 |
| --- | --- | --- |
| ① 资产采集 | 子域名 / 域名 / IP / 端口 / 指纹 / 漏洞 / 邮箱 / 泄露 / DNS / WHOIS / 企业信息 / 资产搜索 | 11 维采集，Provider 插件化架构，密钥门控自动停用 |
| ② 人工审计 | 逐项研判「真实资产 / 误报」 | 支持**全选 / 反选 / 撤销**与批量标记，确认后进入安全扫描 |
| ③ 安全扫描 | 连通性测试 + 指纹识别 + 高危扫描 | 指纹识别已**并入**本流程，对确认资产统一执行：ICMP、登录页识别、敏感端口、未授权访问、明文传输、CVE 高危组件（22,000+ 指纹）。**误报资产直接跳过，不识别**，减少无效耗时 |
| ④ EASM 报告 | HTML / Markdown / DOCX 三格式 | 概览 / 审计结论 / 安全结果 / 漏洞明细（带分类标签）/ 资产清单 / 合规声明；HTML 可「打印 → 另存为 PDF」 |

## 二、安装与运行

要求 **Node.js ≥ 18**（安全扫描依赖内置 `fetch`）、**npm**、Windows 10/11（x64）。

```bash
npm install        # 安装 electron / electron-builder / ping / ip2region
npm start          # 启动桌面窗口（开发）
npm run launch     # 等价于 npm start
```

## 三、使用流程

1. **录入检索维度**：在左侧表单填写根域名 / IP 段 / 企业关键字 / 邮箱后缀 / GitHub 关键字等（至少一项）。
   高级选项中可单独开关采集模块、设置并发数、自定义 DNS 解析器、填写资产搜索引擎密钥。
2. **开始收集**：点击「开始收集」，各维度结果实时流入对应 Tab。
3. **人工审计**（新增 Tab）：
   - 列表自动汇总所有待研判资产（子域名 / IP / 端口目标去重；**邮箱 / 泄露 / 企业信息**也纳入审计）。
   - **IP 与域名类资产**额外展示 `解析IP` / `地理位置` / `连通性`，辅助研判是否为真实资产。
   - **邮箱 / 泄露 / 企业信息类**仅支持人工研判真实性（下拉判定 `未判定 / 真实资产 / 误报`），**不触发扫描**。
   - 每行通过下拉框判定 `未判定 / 真实资产 / 误报`。
   - 工具栏：**全选**、**反选**、**撤销（取消选择）**、**全部标记真实**、**全部标记误报**、**清空判定**。
   - 确认「真实资产」后，点击右侧 **「对确认资产执行安全扫描 →」**（误报资产会被自动跳过）。
4. **安全扫描**（新增 Tab）：对确认资产逐个执行连通性测试与指纹/高危扫描（指纹识别已并入此流程），实时展示开放端口、命中指纹、关联漏洞与风险等级。
5. **EASM 报告**（新增 Tab）：点击 **HTML / Markdown / DOCX** 任一按钮导出报告，保存为对应格式文件。HTML 可在浏览器「打印 → 另存为 PDF」。

## 四、人工审计说明

- 审计以「资产目标」（host / IP）为最小单元，去重后列出。
- **IP / 域名类**会异步 enrichment（DNS 解析 IP + ip2region 地理位置 + ICMP 连通性），结果直接显示在列表中辅助研判。
- **邮箱 / 泄露 / 企业信息类**同样可判定真实性，但属于「非扫描对象」，不触发任何网络扫描。
- `真实资产` 才会被纳入安全扫描与报告；**误报资产在安全扫描中会被直接跳过**（不解析、不识别、不扫描），以节省时间。
- 批量操作作用于**当前勾选行**；未勾选时作用于**全部资产**。

## 五、安全扫描说明（参考 `wanpingqiuzhen`）

对单个确认资产执行：

1. **连通性测试**：ICMP 可达性、响应延迟、解析 IP、离线 IP 地理位置（ip2region）、登录界面识别。
2. **指纹识别（已并入本流程）**：基于内置指纹库（整合 FingerprintHub、wscan-Fingerprint、finger 等开源特征库，22,000+ 产品 / 设备 / 服务指纹）进行 HTTP 响应头 / 响应体 / 标题 / Cookie / favicon / 服务 banner 多维度匹配。
3. **敏感端口探测**：数据库 / 缓存 / 远程管理 / 明文服务等 40+ 端口开放情况。
4. **未授权访问**：Redis / Elasticsearch / Memcached / Docker / etcd / Hadoop / Zookeeper / CouchDB 等。
5. **明文传输检测**：探查目标是否以明文 HTTP 提供服务（HTTPS 并存则降级为「中」）。
6. **漏洞派生与归类**：由命中指纹关联的 CVE 自动派生漏洞项，并统一映射到 12 类标准标签（文件上传、反序列化、SSRF、CSRF、未授权访问、SQL注入、XSS、整数溢出、代码注入、路径遍历、缓冲区溢出、其他）。

输出含开放端口、命中指纹、关联漏洞、风险等级（高 / 中 / 低 / 安全）及命中说明，并汇总各风险档数量。

> **指纹识别逻辑已审查并修复过度匹配**：原先 `body_keywords` / `title_keywords` / `cookie_keywords` 等弱维度子串匹配易被通用词（admin / login / api / manage / console）误触发（实测通用页可触发 30+ 误报）；现引入「命中维度强度」规则——需含 ≥1 个强维度（响应头 / 路径 / favicon / 正则 / banner）或 ≥2 个弱维度才判定为有效命中，单弱维度一律忽略；同时 `scanTarget` 整体 try/catch 兜底，单个资产异常不再中断整批扫描。修复后通用页误报由 40 降至 9 且均为真实命中。

## 六、目录结构

```
万平灵探/
├── main.js                  # Electron 主进程：窗口、IPC 编排、CSV / 报告导出
├── preload.js               # 渲染进程 <-> 主进程 安全桥接（contextBridge）
├── package.json             # 元信息、脚本、electron-builder 配置
├── build/icon.ico           # 打包图标
├── renderer/                # 渲染进程（前端 UI）
│   ├── index.html           # 页面结构（14 Tab：采集 + 人工审计 + 安全扫描 + 报告）
│   ├── renderer.js          # Tab 渲染、审计、安全扫描、报告逻辑
│   └── styles.css           # 样式
└── src/
    ├── core/                # Provider 引擎（BaseProvider / Registry / Engine）
    │   └── vuln-categories.js  # 12 类标准漏洞分类规范与映射
    ├── providers/           # 11 维采集 Provider（子域名 / DNS / IP / 端口 / 指纹 / 漏洞 / 泄露 / 邮箱 / WHOIS / 企业 / 搜索）
    ├── orchestrator.js      # 采集任务编排入口
    ├── secscan/             # 安全扫描（复用 wanpingqiuzhen 引擎）
    │   ├── run.js           # 编排器：连通性 + 指纹/高危，流式回传
    │   ├── connectivity.js  # 连通性检测（ping + 登录页识别）
    │   ├── enrich.js        # 审计 enrichment：解析 IP / 地理位置 / 连通性
    │   ├── port.js          # TCP 端口开放检测
    │   ├── security.js      # 高危指纹安全扫描主流程
    │   ├── geo.js           # 离线 IP 地理（ip2region）
    │   ├── util.js          # 并发池 / 超时 fetch / CSV
    │   ├── ext_fingerprints.js
    │   └── data/            # 指纹特征库（22,000+ 条）
    └── report/
        ├── easm.js          # 格式化 EASM 报告（自包含 HTML）生成
        ├── model.js         # 报告数据归一化（三格式共用）
        ├── markdown.js      # Markdown 报告生成
        └── docx.js          # DOCX 报告生成（无第三方依赖，自组 OOXML/ZIP）
```

## 七、配置

- **资产搜索引擎密钥**（FOFA / Shodan / ZoomEye / Quake / Hunter / ENScan）：在高级选项中填写，留空则对应模块自动停用。
- **自定义 DNS 解析器**：受限网络下可填写 `8.8.8.8, 1.1.1.1` 提升可用性。
- **并发数 / 每网段 IP 数**：高级选项中调节，平衡速度与稳定性。
